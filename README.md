# Aggiornamenti Vendor

Repository di distribuzione del plugin WordPress Aggiornamenti Vendor (GPL-2.0-or-later).
Contiene solo il codice rilasciato.

**Installazione:** dall'ultima Release scarica `aggiornamenti-vendor-X.Y.Z.zip` (sezione *Assets*) e caricalo da Plugin → Aggiungi nuovo → Carica plugin.
I file *Source code* generati da GitHub non sono installabili su WordPress.

I siti con il plugin installato ricevono da qui gli aggiornamenti (zip verificato con SHA-256).
